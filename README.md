C++ Class, Constructor, Destructor and User-defined Functions
Practical Assignment

This project demonstrates basic Object-Oriented Programming concepts in C++ using a Student class.

Objectives
1. To Understand the concept of class and object in C++.
2. To create and use user -defined member functions.
3. To implement constructor and destructor.
4. To understand object and destructor.

Problem Statement

Write a C++ program to demonstrate the use of a class, constructor, destructor, and user-defined functions. The program should create a Student object, store student details, display the details, and check the student's result.

Concepts Used
Class:
A class is a user-defined data type in C++ that combines data members and member functions 
into a single unit. Objects are created from class.
Constructor:
A constructor is a special function that has the same name as class. It is automatically called when object is created 
Destructor:
A destructor is a special member function whose name is the class name preceded by ~. It is automatically called when object is destroyed .
User-Defined Function: 
A user-defined function is a function created by programmer to perform special task. In this program member functions used to accept, calculate and display the data.


The program creates a Student object with the following details:

Name: Shivam Salunkhe
Roll No: 101
Marks: 85.5

The program then displays the details and checks the result.

Algorithm
Start the program.
Define a Student class.
Declare data members for name, roll number, and marks.
Create a parameterized constructor to initialize the data.
Define the display() user-defined function.
Define the checkResult() user-defined function.
Define the destructor.
Create a Student object in the main() function.
Display the student details.
Check and display the result.
End the program.
Technology Used
Programming Language: C++
IDE: Dev-C++
Libraries: <iostream>, <string>
